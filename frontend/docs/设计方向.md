# 水韵江苏 · 设计方向

> 目标：让「银龄守护」看起来像成熟的长者照护服务，而不是一个套壳聊天工具。聊天退为「小助手」，首页主推记忆、守护、健康、反诈。

## 1. 设计判断

- 产品类型：面向长者与家属的照护产品，不是营销落地页。
- 气质：安静、可信、有地方文化质感，避免“AI 工具感”。
- 受众约束：长者视力、点击精度、阅读耐心优先；家属需要信息密度。
- 主题：水韵江苏。用纸感、墨色、青瓷绿、水乡主视觉和宋体标题建立气质。
- 主题锁定：全站浅色，不切换深色，保证长者阅读对比度。

设计参数：`VARIANCE 5 / MOTION 3 / DENSITY 4`。动效只用于状态反馈和页面进入，不做装饰性循环。

| 墨软 | `#46554F` | 次级正文 |

约束：

- 主色只有青瓷绿；印章红只做品牌印章和高风险语义，不用于普通按钮。
- 不使用紫色渐变、霓虹、玻璃拟态和重阴影。
- 风险评估不能只靠颜色，必须同时有文字。

## 3. 字体

- 标题：`"Songti SC", "Noto Serif SC", "STSong", "SimSun", "Source Han Serif SC", serif`。用于页面标题、模块标题、故事正文。
- 正文：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`。
- 不引入 Google Fonts CDN；使用系统字体栈，比赛现场更稳定。
- 标题字重 600，不追求超粗；正文行高 1.7 到 1.9。
- 长者模式：导航与按钮增大，说明文字不低于 15px。

## 4. 形状与层级

- 容器圆角 `2px`，按钮和输入框也是 `2px`；标签/状态可以用全圆角。
- 不使用大面积阴影；用 1px 细线、留白和字重建立层级。
- 一屏只放一个主任务；首页模块按内容重要性排布，不做三等分卡片。
- 主视觉：AI 生成的水乡清晨图，已压缩为 WebP。后续可替换为实拍或已授权图片。

## 5. 信息架构

### 长者端

导航：**今日 / 故事 / 健康 / 守护**。

- 今日：状态条（用药、位置、待确认）、记忆故事、安心守护、健康照护、反诈守护、小助手入口。
- 故事：时间轴、访谈、故事章节、朗读。
- 健康：今日用药、服药记录、拍照识药。
- 守护：安全区域示意图、位置、越界提醒、寻人海报、反诈鉴定。
- 小助手：聊天从主导航移除，作为右上角次级入口和首页一行文字入口。

### 家属端

- 照护概览：位置、用药、安全提醒、记忆数。
- 本周照护简报：用药、安全、陪伴、待确认四块，加建议。
- 待确认事项：转账确认、拒绝/确认、96110。

### 角色页

左侧竖排「长者 / 家属 / 机构」，右侧水乡主视觉。不使用三张等宽功能卡。

## 6. 避免的 AI 味

- 不用紫色渐变、发光按钮、sparkles 图标堆叠。
- 不用“AI 助手”作为首页主角。
- 不用三列等宽卡片和满屏圆角卡片。
- 不用假截图、假数据、假精确指标。
- 不用空泛文案（“赋能”“无缝”“下一代”）。
- 演示数据里的用药、位置、告警都来自真实接口，没有记录时显示“暂无记录”。

## 7. 可访问性

- 正文对比度达到 WCAG AA；辅助文字使用更深的灰绿。
- 长者端按钮高度不低于 48px，主按钮更大。
- 所有风险状态同时有颜色、图标和文字。
- 支持 `prefers-reduced-motion`，关闭过渡与动画。
- 聊天、访谈、寻人表单都提供错误状态和重试入口。
