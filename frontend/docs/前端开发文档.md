# 银龄守护 · 前端开发文档

> 版本：v0.1（2026-10-21）
> 适用：`frontend`（React 18 + Vite 6 + TypeScript）
> 文档关系：产品/总体架构看《开发设计文档》；接口字段看《接口契约》。本文件只写前端实现。

---

## 1. 范围与目标

### 1.1 前端负责什么

- 三端界面：长者端、家属端、机构端（P1）。
- AI 交互：流式回答、工具调用过程、引用、确认弹窗、错误兜底。
- 多模态输入：语音、拍照/上传、粘贴截图。
- 安全交互：反诈结果、冷静期倒计时、家属确认、围栏、寻人海报。
- 记忆交互：访谈、故事时间轴、章节朗读、家属批注、导出。
- 适老化与无障碍：大字号、高对比、语音优先、少层级。

### 1.2 前端不负责什么

- 不直接调用模型/地图服务端 Key；不接触 Prompt。
- 不做最终权限校验（后端强制拦截）。
- 不做真实转账/拨号；只做提示、确认和 `tel:` 跳转。
- 不做 AI 结果的事实判断；只负责展示、引用和风险标识。

### 1.3 P0 页面

角色选择、长者首页、Agent 对话、记忆列表/访谈/章节、用药、安心守护首页/反诈/位置、家属概览/告警/确认/记忆、设置。

## 2. 技术栈与工程约定

| 项 | 约定 |
|---|---|
| 框架 | React 18 + Vite 6 + TypeScript strict |
| 路由 | react-router-dom 6 |
| 样式 | 现有 `styles.css` + `token.css`，不引入 Tailwind/组件库 |
| 图标 | lucide-react（已有） |
| 数据 | 原生 `fetch` + 自定义 hooks；不引入 TanStack Query |
| 流式 | `fetch` + `ReadableStream` 手写 SSE 解析 |
| 地图 | 高德 JS API（动态加载）；无 Key 时降级示意图 |
| 测试 | Vitest + React Testing Library + Playwright |
| 代码规范 | ESLint + Prettier（新增）；`tsc --noEmit` 必须通过 |
| 环境变量 | `VITE_API_BASE_URL`、`VITE_USE_MOCKS`、`VITE_AMAP_JS_KEY` |

**约束：**

- 不新增重型依赖；新增依赖需说明体积和替代方案。
- 所有 API 类型来自 `@eha/shared`，不在前端重复定义。
- 所有用户可见文案走统一文案表（见 §14），不散落在组件里。
- 长者端禁止使用小于 16px 的文字；主按钮 ≥ 64px。

## 4. 路由与角色守卫

```tsx
// routes.tsx 伪代码
<Routes>
  <Route path="/" element={<RoleSelectPage />} />
  <Route element={<RequireRole role="elder"><ElderLayout /></RequireRole>}>
    <Route path="/elder" element={<ElderHomePage />} />
    <Route path="/elder/chat" element={<AgentChatPage />} />
    <Route path="/elder/story" element={<MemoryListPage />} />
    <Route path="/elder/story/new" element={<MemoryInterviewPage />} />
    <Route path="/elder/story/:id" element={<StoryChapterPage />} />
    <Route path="/elder/meds" element={<MedicationsPage />} />
    <Route path="/elder/safety" element={<SafetyHomePage />} />
    <Route path="/elder/safety/scam" element={<ScamCheckPage />} />
    <Route path="/elder/safety/location" element={<LocationPage />} />
  </Route>
  <Route element={<RequireRole role="family"><FamilyLayout /></RequireRole>}>
    <Route path="/family" element={<FamilyDashboardPage />} />
    <Route path="/family/alerts" element={<FamilyAlertsPage />} />
    <Route path="/family/confirm" element={<FamilyConfirmPage />} />
    <Route path="/family/memory" element={<FamilyMemoryPage />} />
    <Route path="/family/report" element={<FamilyReportPage />} />
  </Route>
  <Route path="/institution" element={<RequireRole role="institution"><InstitutionPage /></RequireRole>} />
  <Route path="/settings" element={<SettingsPage />} />
</Routes>
```

**守卫规则：**

- 未登录 → 跳 `/`，显示「请选择身份」。
- 角色不匹配 → 跳自己的首页，toast「当前身份无法访问」。
- 所有路由懒加载：`React.lazy` + `Suspense` + `LoadingSkeleton`。
- 删除旧路由：`/home/child`、`/home/adult`、`/settings/alipay-bind`。

## 5. 页面规格

> 每个页面：目标 → 布局 → 状态 → 交互 → API → 验收。

### 5.1 角色选择 `/`

**目标：** 让评委/用户 5 秒内进入演示。

**布局：**

```
银龄守护（大标题 + 一句话）
[长者模式] [家属模式] [机构模式]
[一键体验：李奶奶的家]   ← 演示账号
底部：隐私说明 / 开源声明
```

**交互：**

- 点击角色 → `POST /api/auth/demo-login` → 跳对应首页。
- 演示模式显示「这是一个演示环境，数据均为虚构」。
- 记住上次角色（localStorage），但不自动登录。

**验收：** 3 个角色可进入；未登录访问 `/elder` 会跳回；长者模式字体明显更大。

---

### 5.2 长者首页 `/elder`

**目标：** 一屏完成「说话 / 求助 / 防骗」三个动作。

**布局：**

```
[顶部：李奶奶，早上好] [语音播报开关]
[大卡片：我想说说话]      → /elder/chat
[大卡片：我找不到家了]    → /elder/safety/location?mode=sos
[大卡片：有人让我转账]    → /elder/safety/scam?mode=transfer
[小入口：我的故事] [吃药提醒] [联系家人]
[状态条：今天有 2 次用药 / 家属已连接]
```

**状态：**

- 今天有未完成用药 → 卡片红色角标「2 次待吃」。
- 有未处理告警 → 顶部黄色提示条。
- 离线 → 顶部「网络未连接，部分功能不可用」。

**交互：**

- 点击「我想说说话」→ 进入聊天并自动聚焦输入框；可选自动语音问候。
- 点击「我找不到家了」→ 进入位置页并弹出「通知家属」确认。
- 点击「有人让我转账」→ 进入反诈页并默认选中「转账冷静期」。
- 「联系家人」→ 一键拨号（`tel:`）或发送家属消息。

**验收：** 三个大按钮在 375px 宽屏不换行；按钮高度 ≥ 64px；点击区域足够；语音播报可关闭。

### 5.3 Agent 对话 `/elder/chat`

**目标：** 让老人用说话解决问题，让评委看见 Agent 的工具调用。

**布局：**

```
[顶部：返回 | 银龄守护 | 语音开关 | 清空]
[消息区]
  ├─ 用户气泡（文字/语音图标/图片缩略图）
  ├─ AI 气泡（流式文字）
  ├─ 工具卡片（可折叠：正在查询天气… / 已完成）
  ├─ 引用卡片（来源列表）
  └─ 风险提示条（高风险时）
[确认弹窗（高风险工具）]
[输入区：按住说话 | 输入框 | 拍照 | 发送/停止]
[快捷问题：今天天气 / 我该吃药了吗 / 这是不是骗子]
```

**状态机：**

```
idle → sending → streaming → (tool_running → streaming)*
     → confirmation_required → waiting_user → (resume | cancel)
     → done | error
```

**交互细节：**

- 发送后立即插入用户消息；显示「正在想…」三点动画。
- 收到 `tool_call` 时插入工具卡片，显示工具名 + 参数摘要 + 状态；`tool_result` 更新为完成/失败。
- 收到 `confirmation_required` 时关闭流，弹出确认弹窗；确认后带 `confirmationId` 重新请求。
- 收到 `token` 追加到当前 AI 气泡；用户上滑时暂停自动滚动。
- 「停止」→ `AbortController.abort()`；保留已生成内容，显示「已停止」。
- 高风险横幅：红色/橙色 + 图标 + 文字 + 「联系家人」「拨打 96110」按钮。
- 引用卡片：标题 + 域名 + 展开；不直接打开不可信链接（只展示来源）。
- 语音模式：按住说话；松开发送；识别中显示波形/「我在听」；识别失败可重试。
- 图片：拍照/上传后先显示缩略图，再随消息发送。
- 空状态：三个快捷问题 + 「您可以直接说话」。

**API：** `POST /api/agent/chat`（SSE）；`POST /api/agent/confirm` 见契约。

**验收：**

1. 正常回答首 token < 2.5s；工具调用可见；可停止。
2. 高风险确认弹窗出现，确认/取消都正确继续/结束。
3. 断网/超时显示可读错误 + 重试。
4. 语音不可用时显示「当前浏览器不支持语音，请打字」。
5. 长者模式下文字 ≥ 18px、按钮 ≥ 48px。

### 5.4 记忆列表 `/elder/story`

**目标：** 让老人看到「我说过的话被整理成了故事」。

**布局：**

```
[标题：我的故事] [开始新故事]
[时间轴]
  1978 苏州河边的夏天   [3 张照片] [听故事]
  1985 儿子出生
  2010 退休后学昆曲
[空状态：还没有故事，点这里说说您年轻时的事]
```

**状态：** 加载骨架；空状态；错误重试；分页加载。

**交互：** 点卡片进章节；长按/菜单删除（二次确认）；「开始新故事」进访谈。

**API：** `GET /api/memory/items`、`GET /api/memory/story/:id`。

**验收：** 时间轴按时间排序；空状态有引导；删除有确认；长者模式卡片大。

### 5.5 记忆访谈 `/elder/story/new`

**目标：** 一次只问一个问题，老人按着说话即可。

**布局：**

```
[进度：第 2/8 个问题]
[照片预览（如有）]
[AI 问题（大字）：这张照片是在哪里拍的？]
[按住说话 / 重录 / 跳过]
[识别文字预览（可编辑）]
[下一步]
```

**交互：**

- 进入时 `POST /api/memory/interview/start`，拿第一个问题。
- 录音 → ASR → 文本预览 → 用户确认 → `POST /api/memory/interview/:id/answer`。
- 支持「跳过」「不想说」；不追问敏感话题。
- `done=true` → 展示结构化记忆 → 「保存到我的故事」。
- 失败：保留已录内容，允许重试；不丢数据。

**验收：** 5 轮可完成；可跳过；识别文本可编辑；保存后出现在时间轴；长者模式大按钮。

### 5.6 故事章节 `/elder/story/:id`

**目标：** 让老人/家属读故事、听故事、分享故事。

**布局：**

```
[标题 + 时间 + 标签]
[照片轮播/网格]
[正文（大字，段落）]
[播放朗读] [数字人讲述]
[家属批注（家属端可见）]
[分享] [导出 PDF]
```

**交互：**

- 「播放朗读」→ `POST /api/memory/story/:id/audio` → `<audio>` 播放；失败降级浏览器 TTS。
- 「数字人讲述」→ 打开 `DigitalHumanPanel`（narrator 模式）；加载失败降级 TTS。
- 「分享」→ 生成 24h 链接；复制/二维码；可撤销。
- 「导出 PDF」→ 服务端生成，返回下载链接。

**验收：** 正文可读（≥18px/1.8 行高）；音频可暂停；数字人失败不白屏；分享链接过期提示。

### 5.7 用药 `/elder/meds`

**目标：** 让老人知道「今天吃什么、吃没吃」，让家属看到依从率。

**布局：**

```
[今天：2 次待吃 / 1 次已完成]
[拍照识药（大按钮）]
[药物卡片：氨氯地平 5mg 08:00 [已吃] [稍后]]
[用药记录]
[免责声明]
```

**交互：**

- 拍照 → `POST /api/medications/scan` → 结果卡片（药名/用法/禁忌/来源/置信度）。
- 低置信度 → 黄色提示「我不太确定，请让家人或药师确认」，不自动加入计划。
- 「已吃/稍后/跳过」→ `POST /api/medications/log`。
- 红旗症状问题 → Agent 直接给急救建议，不进入普通问答。

**验收：** 拍照 8 秒内出结果；低置信度不猜；打卡后状态即时更新；家属端可见依从率。

### 5.9 反诈鉴定 `/elder/safety/scam`

**目标：** 老人/家属 30 秒内判断「这是不是骗子」，并进入冷静期。

**布局：**

```
[三个 Tab：粘贴文字 | 上传截图 | 输入链接]
[输入区]
[开始鉴定]
[结果卡片]
  ├─ 风险等级（高/中/低/不确定）
  ├─ 诈骗类型
  ├─ 红旗证据（逐条引用原文）
  ├─ 建议动作（不转账/联系家人/96110）
  ├─ 引用来源
  └─ [启动转账冷静期] [联系家人] [拨打 96110]
[冷静期：60 秒倒计时 + 家属确认状态]
```

**交互：**

- 支持粘贴（`navigator.clipboard.readText`，需用户手势）、拍照、上传、输入 URL。
- 结果高亮：高风险红色 + 图标 + 文字，不只靠颜色。
- 「启动转账冷静期」→ `POST /api/safety/cooling-off` → 倒计时；家属端收到确认。
- 倒计时结束/家属拒绝 → 显示「已阻止/已通知家属」；不执行转账。
- 免责声明固定展示：「AI 只能辅助判断，不能替代警方/银行」。

**验收：**

1. 上传含「安全账户」的截图，8 秒内出高风险 + ≥3 条红旗。
2. 高风险时冷静期按钮显著；家属确认状态实时更新。
3. 低置信度显示「不确定」，不硬判。
4. 链接结果不自动打开目标页面。

### 5.10 位置/围栏 `/elder/safety/location`

**目标：** 家属看位置、设围栏；老人一键求助。

**布局（长者视角）：**

```
[我的位置：南京市鼓楼区（模糊）]
[最后更新：2 分钟前]
[我在安全范围内 / 已离开安全范围]
[通知家人] [我找不到家了]
```

**布局（家属视角）：**

```
[地图 + 老人标记 + 围栏]
[最后位置/时间/电量]
[围栏列表：家 800m / 公园 1.2km]
[添加围栏]
[轨迹回放]
[一键寻人]
[告警记录]
```

**交互：**

- 地图懒加载；无 Key 时显示示意图 + 坐标列表。
- 围栏：圆形（P0）；拖拽中心/半径；生效时段；进出提醒。

## 8. SSE 客户端

### 8.1 解析器

```ts
// lib/sse.ts
export async function streamSSE(
  url: string,
  body: unknown,
  onEvent: (event: string, data: any) => void,
  signal?: AbortSignal
) {
  const res = await fetch(url, {
    method: "POST",
    headers: { "content-type": "application/json", accept: "text/event-stream" },
    credentials: "include",
    body: JSON.stringify(body),
    signal
  });
  if (!res.ok || !res.body) throw await toApiError(res);

  const reader = res.body.getReader();
  const decoder = new TextDecoder();
  let buffer = "";
  while (true) {
    const { done, value } = await reader.read();
    if (done) break;
    buffer += decoder.decode(value, { stream: true });
    const blocks = buffer.split("\n\n");
    buffer = blocks.pop() ?? "";
    for (const block of blocks) {
      if (block.startsWith(":")) continue; // keep-alive
      const ev = parseBlock(block); // event: xxx / data: {...}
      if (ev) onEvent(ev.event, ev.data);
    }
  }
}
```

### 8.2 事件处理

| 事件 | 前端动作 |
|---|---|
| `meta` | 记录 sessionId/requestId |
| `token` | 追加到当前 AI 消息 |
| `tool_call` | 插入工具卡片（running） |
| `tool_result` | 更新工具卡片（ok/fail + 耗时） |
| `confirmation_required` | 关闭流，弹确认框 |
| `done` | 标记完成，渲染引用/免责声明 |
| `error` | 显示错误卡片 + 重试 |

- 流结束但没收到 `done` → 视为异常，提示「回答中断，请重试」。
- 用户点停止 → abort，保留已有 token，状态标记「已停止」。

## 9. 语音与多模态

### 9.1 ASR

- 使用 `SpeechRecognition` / `webkitSpeechRecognition`；仅 Chrome/Edge 稳定，Safari 部分，Firefox 不支持。
- 不支持时：隐藏语音按钮，显示「请打字」；不报错。
- 权限：首次点击时请求；`not-allowed` → 提示去浏览器设置。
- 录音状态：`starting → listening → stopped/error`；显示波形/文字。
- 识别文本先预览，用户确认后发送（长者模式）。
- 失败可重试；不丢已识别内容。

### 9.2 TTS

- `speechSynthesis`；首次用户手势解锁。
- 长者模式默认自动播报；可一键关闭。
- 长文本分段播放；切换页面/停止按钮取消。
- 数字人失败时自动降级 TTS。
- 播报时显示「正在说话」+ 停止按钮。

### 9.3 图片

- 相机：`<input type="file" accept="image/*" capture="environment">`。
- 压缩：canvas 最长边 1600px，JPEG/WebP 0.8；原图 > 10MB 拒绝。
- 上传：`POST /api/uploads`；显示进度；失败重试。
- 截图：支持粘贴板（`paste` 事件）读取图片。
- 预览：缩略图 + 删除。

## 12. 适老化与无障碍

### 12.1 长者模式

- 字号：标准 1.0 / 大 1.25 / 超大 1.5；默认大。
- 行高 ≥ 1.6；段落短；每屏一个主任务。
- 按钮 ≥ 64px 高；图标 + 文字；避免纯图标。
- 对比度 ≥ 4.5:1；风险色 + 图标 + 文字。
- 语音优先；可关闭自动播报。
- 二次确认：呼救 3 秒、转账 60 秒，均可取消。

### 12.2 无障碍

- 焦点可见；Tab 顺序合理；弹窗焦点锁定。
- `aria-live="polite"` 用于流式回答（避免打断读屏）。
- 图片有 alt；图标按钮有 aria-label。
- 支持键盘操作；不依赖 hover。
- 尊重 `prefers-reduced-motion`。
- 表单错误与字段关联；不用仅颜色表达错误。

### 12.3 文案

- 不用「大模型」「RAG」「Agent」等术语；用「我帮您查」「我记下了」。
- 错误说人话 + 下一步；不显示堆栈。
- 医疗/金融必须带免责声明。

## 附录 B：SSE 状态机

```
[send] → connecting
  → streaming ──token──→ streaming
  → tool_call → tool_running → tool_result → streaming
  → confirmation_required → waiting_user
       ├─ approve → connecting → streaming → done
       └─ cancel → done
  → done | error
[stop] → aborted (保留已生成内容)
```

## 附录 C：组件验收要点

- `BigActionCard`：键盘 Enter/Space 可触发；focus ring 可见。
- `ToolTrace`：默认折叠；展开显示参数摘要/结果；失败有原因。
- `CoolingOffTimer`：倒计时准确；后台标签页回来不漂移（用 `expiresAt` 计算）。
- `ConfirmationDialog`：焦点锁定；Esc 取消；倒计时结束自动取消。
- `MapPanel`：无 Key 时 fallback；加载不阻塞页面。
- `DigitalHumanPanel`：15s 超时降级；不自动播放声音。
- `MissingPosterPreview`：发布前二次确认；脱敏提示。
