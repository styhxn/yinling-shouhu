# 智伴银龄 项目概述

> 仓库：`zhiban-yinling-system`
> 定位：具身智能生活陪伴系统（基础框架）
> 架构：本地优先 + 可选云端，前后端分离，能力以适配层接口占位、默认 Mock 保证可运行

---

## 1. 一句话定位

面向老年人群的生活陪伴系统骨架：把语音、摄像头、健康数据、提醒、紧急呼叫、数字具身孪生体与问答等能力，通过统一适配层和事件总线串起来，本地可独立运行，云端能力按需接入。

---

## 2. 技术栈

| 层 | 选型 |
|---|---|
| 包管理 | npm workspaces（monorepo：`apps/*` + `packages/*`） |
| 后端 | Fastify 5（`@fastify/cors` / `multipart` / `static` / `websocket`）、TypeScript、tsx 热重载、zod 校验、sharp 图像处理 |
| 前端 | React 18 + Vite 6 + react-router-dom 6 + react-easy-crop |
| 共享层 | `@eha/shared`：zod schemas + 类型定义 |
| 适配层 | `@eha/adapters`：能力接口 + Mock 实现 |
| 测试 | vitest |
| 存储 | 本地 JSON 文件 + AES 加密敏感字段（原子写入） |

## 4. 核心能力（按域）

### 后端路由（`apps/api`）
- `/health` 健康检查
- `/privacy` 隐私设置（相机/麦克风开关、自动休眠、云同步、数据导出、自动播报）
- `/profile` 用户档案（昵称、性别、年龄、身高体重、过敏史、病史、紧急联系人、地址、头像）
- `/records` 生活数据记录与趋势指标（TrendMetric）
- `/qa` 问答（接入大模型）
- `/emergency` 紧急呼叫（一键呼救、事件记录）
- `/reminders` 提醒（药物 / 运动 / 自检 / 喝水）
- `/weather` 天气（实时 + 24h 预报）
- `/vitality` 活力评分（历史 365 条，含风险因子）
- `/mock` 模拟事件注入（跌倒、久坐、提醒到期、紧急、问答、活力告警、陪伴指令）
- `/ws` WebSocket 实时事件推送（AppEvent）
- `/dh-live-api` 数字人流式问答（NDJSON）

### 前端页面（`apps/web`）
入口页 → 老年 / 成人 / 儿童三模式首页（字体缩放不同）→ 监控 / 健康建议 / 提醒 / 问答 / 紧急 / 记录 / 智能陪伴 / 设备 / 地址 / 设置 / 支付宝绑定。
全局含可拖拽、带 3 秒倒计时确认的一键呼救悬浮按钮。

### 适配层接口（`packages/adapters`）
统一抽象硬件与云端能力，默认提供 Mock 实现，便于无设备时跑通：
问答引擎、唤醒词、ASR、TTS、跌倒检测、久坐检测、手势/动作检测、穿戴设备接入（华为/小米/通用）、云同步、机器人执行器（表情/手势/灯光）、健康建议引擎（风险等级+建议）、提醒调度、紧急通知。

## 5. 数据模型要点（`packages/shared`）
- `Profile` / `UserInfo`：个人档案与病史、联系人、地址
- `PrivacySettings`：隐私与播报开关
- `Weather*`（Today / Realtime / Forecast24h）：天气数据
- `WearablesStatus`：穿戴设备连接状态与指标
- `TrendMetric`：通用趋势指标（type/value/ts/source）
- `AppEvent`：事件总线统一事件（跌倒、久坐、提醒到期、紧急、问答、活力告警、陪伴指令等）

---

## 6. 数据存储与隐私
- 本地文件 `data/store.json`，敏感字段经 AES 加密（`crypto.ts` 自动生成 master key），普通字段明文。
- 原子写入：先写 `store.json.tmp` 再 `rename`，避免损坏。
- 隐私默认关闭云同步（`cloudSyncEnabled: false`），数据导出、自动播报可配。
- API 启用 CORS、上传限 6MB、JSON 空体校验。

---

## 7. 大模型集成
- **问答 / 数字人**：`services/llm.ts` 对接 OpenAI 兼容接口，支持 **豆包(Ark)、DeepSeek、通义千问、讯飞星火** 多 provider。
- 容错机制：令牌桶限流、超时、指数退避重试、多 provider 自动 fallback。
- 数字人（`DH_Live`）通过 `/dh-live-api/eb_stream` 以 **NDJSON** 流式返回文本；前端用浏览器 `SpeechSynthesis` 做 TTS，无需本地模型。
- 未配置任何模型即返回 `503 missing_config`。

## 8. 运行与校验
```bash
npm i                  # 安装所有 workspace 依赖
npm run dev            # 并行启动 api(3100) + web(5173)
npm run verify         # 校验：build packages → typecheck → build apps → test
```
- Web：`http://localhost:5173/`
- API：`http://127.0.0.1:3100/`
- 数字人静态资源：`/dh-live/*`（构建产物 `apps/web/dist/dh-live`）

---

## 9. 项目现状与定位
当前是**可运行的基础框架/骨架**，而非完整产品：
- 全部硬件与云端能力走适配层 + Mock，未接真实设备。
- 大模型为真实调用，需自行配置 API Key。
- 目标是把"陪伴"所需的模块先搭全、跑通链路（含数字人），后续再逐一替换 Mock 为真实实现。
