# 银龄守护 · 项目概述

> 定位：会倾听、也会守护的江苏长者 AI 陪伴系统
> 架构：本地优先 + 可选云端，前后端分离；`frontend` 可独立交接
> 参赛：江苏省赛提交 2026-11-18，国赛 2026-12-27

---

## 1. 一句话定位

围绕“记忆、安全、健康、家属协同”四个真实场景，把 Agent 工具调用、RAG、多模态、安全护栏与实时告警串成一条**可解释、可回查、可演示**的闭环；聊天只是入口之一，不是全部。

---

## 2. 四个核心闭环

| 闭环 | 用户价值 | 关键能力 |
|---|---|---|
| 银龄记忆 | “我说过的话，被认真整理成了故事” | 自适应访谈 → 结构化记忆 → 故事章节 → 口述依据回查 → 可打印故事书 |
| 安心守护 | “拿不准的时候，有人帮我判断” | 规则 + 模型反诈鉴定、截图/链接分析、转账冷静期、家属确认、电子围栏与实时告警、寻人海报 |
| 健康用药 | “该吃什么、吃没吃，有人提醒” | 用药计划、药盒拍照识别、服药打卡、依从率、低置信度不自动入计划 |
| 家属协同 | “不在身边，也能知道关键变化” | 家属概览、待确认、告警知悉、周报、故事阅读 |

AI 深度集中在：Agent 多步工具调用与确认门、记忆检索引用、混合反诈判定、动态反诈演练、故事忠实度校验、可复现评测。

---

## 3. 技术栈

| 层 | 选型 |
|---|---|
| 包管理 | npm workspaces（`frontend` + `apps/*` + `packages/*`） |
| 前端 | React 18 + Vite 6 + TypeScript strict + react-router-dom；自研“水韵江苏”设计系统 |
| 后端 | Fastify 5 + TypeScript + zod + `node:sqlite` |
| 实时 | SSE（Agent 流式）+ WebSocket（位置/告警/家属确认） |
| AI | `ModelRouter` 统一路由：Mock / OpenAI 兼容（DeepSeek、通义千问、火山方舟等） |
| 多模态 | 图片上传重编码去 EXIF；药盒/聊天截图视觉识别；浏览器 ASR/TTS |
| 存储 | SQLite（WAL）+ AES-256-GCM 加密敏感字段 + 启动自动迁移 |
| 测试 | Vitest（单元/集成/接口）；评测 CLI（反诈 + 故事） |
| 部署 | 单进程静态托管 + Docker Compose + Nginx/Caddy |

## 5. 当前实现范围

### 前端路由

| 路径 | 页面 |
|---|---|
| `/` | 角色选择（长者 / 家属） |
| `/elder` | 今日首页：问候、天气、用药、安全、故事入口 |
| `/elder/chat` | 小助手：流式回答、工具卡片、记忆/来源引用、确认弹窗 |
| `/elder/story` | 我的故事：记忆时间轴 |
| `/elder/story/new` | 记忆访谈：照片提问、动态追问、结构化洞见 |
| `/elder/story/:id` | 故事章节：正文、口述依据、朗读、导出 |
| `/elder/meds` | 用药：计划、打卡、拍照识药 |
| `/elder/safety` | 安心守护：位置共享、围栏状态、告警、反诈入口 |
| `/elder/safety/scam` | 反诈鉴定：文字/截图/链接 + 冷静期 |
| `/elder/safety/roleplay` | 反诈演练：动态话术 + 六维报告 |
| `/family` | 家属概览：位置、用药、告警、待确认、周报、故事 |

### 后端能力

- 鉴权：演示登录、HttpOnly 签名 Cookie、RBAC、老人归属校验。
- Agent：工具注册表、4 步循环、高风险确认门、SSE、会话恢复、记忆引用。
- 记忆：访谈状态机、自适应追问、结构化整理、故事生成与忠实度、导出。
- 安全：规则/模型混合反诈、知识库检索、截图识别、冷静期、家属确认、围栏、告警、寻人海报。
- 健康：用药计划、拍照识药、服药日志、依从率。
- 家属：概览、周报、确认与告警处理。
- 实时：WS 鉴权、按老人过滤、心跳与重连。
- 工程：限流、CORS 白名单、安全头、数据保留清理、审计日志、优雅关闭。

## 6. AI 设计要点

- **ModelRouter**：按任务选择 provider，统一超时、重试、限流、Mock 降级；业务代码不直接读 Key。
- **工具调用**：`get_weather`、`get_medications`、`check_scam`、`search_memories`、`start_cooling_off` 等；高风险工具必须确认。
- **记忆引用**：回答过去经历前先 `search_memories`，引用随 `done` 下发；没有依据就明确说没找到。
- **反诈可信度**：规则给底线，模型补解释；模型引语必须逐字命中原文，否则丢弃；失败回退规则。
- **故事忠实度**：引号内容逐字对照口述，未命中去掉引号；用 2-gram 重合度分级并给出警告。
- **演练安全**：动态生成诈骗话术，但过滤真实链接/手机号，报告只做练习建议，不下反诈结论。
- **可复现评测**：11 条固定用例（8 反诈 + 3 故事），指标写入 `eval_cases/eval_runs`，`npm run eval` 可接 CI。

## 7. 安全与隐私

- 敏感字段（访谈原文、精确坐标、联系方式等）AES-256-GCM 加密，主密钥不入库、不入仓库。
- RBAC：长者仅自己；家属仅已绑定老人；机构仅脱敏聚合；管理员可运维。
- 上传：类型/大小校验，图片服务端重编码去 EXIF。
- 日志脱敏；审计记录登录、确认、呼救、冷静期、海报、导出等操作。
- 数据保留可配：位置 90 天、工具日志 30 天、审计 180 天、已处理告警 180 天、过期海报 7 天。
- 生产默认 `Secure` Cookie、CORS 白名单、安全响应头与五桶限流。

## 8. 运行与校验

```bash
npm i
npm run dev          # API + 前端
npm run verify       # 类型检查 + 构建 + 全部测试
npm run eval         # AI 评测（默认 Mock）
```

- 前端：`http://localhost:5173`
- 后端：`http://127.0.0.1:3100`（以 `apps/api/.env` 的 `PORT` 为准）
- 演示登录：`POST /api/auth/demo-login`，body `{"role":"elder"}`
- 无模型 Key 时：`LLM_MOCK=1 DEMO_MODE=1 npm run dev -w apps/api`

## 9. 边界与说明

- 演示数据仅用于比赛展示，不对应真实老人。
- 反诈/医疗结论均为辅助判断，不替代警方、银行、医生。
- 未配置地图 Key 时使用示意地图与演示坐标；未配置模型 Key 时使用确定性 Mock。
- 数字人静态资源来自 DH_live（MIT）；示例头像仅用于比赛演示，商业使用需遵循上游授权。
- 当前定位为可运行、可评测的比赛版本，不是医疗器械或金融风控产品。
