# 演示脚本（预指导 / 答辩）

> 目标：5–8 分钟讲清「这不是普通聊天机器人，而是会用工具、会守护、可解释的长辈 AI」。
> 演示前按本页准备，演示后按「重置」恢复数据。

## 1. 演示前 10 分钟

1. 用 **Edge** 打开（Chrome 国内语音识别容易 `network` 失败）。
2. 语音必须走 **localhost 或 HTTPS**：
   - 本机：`npm run dev`，打开 `http://localhost:5173`
   - 线上：`ssh -L 33200:127.0.0.1:3200 root@<服务器IP>`，打开 `http://localhost:33200`
3. 检查音箱/麦克风；首次点语音按钮时允许麦克风权限。
4. 需要恢复初始数据时：

```bash
npm run reset:demo -- --yes
# 线上：在服务器项目目录执行；或调用 POST /api/admin/reset-demo
```

5. 打开 `/`，确认能看到「长辈演示 / 家人演示」两个入口。

## 2. 体验账号

| 角色 | 进入方式 | 说明 |
| --- | --- | --- |
| 长辈 | `/` → 长辈演示 | 李奶奶，预置健康档案、用药、记忆、位置 |
| 家人 | `/` → 家人演示 | 小李（女儿），可看概览、留言、确认告警 |
| 家人手机号 | `/login/family`：`13800001234` | 演示验证码 `123456` |
| 长辈绑定码 | `/login/elder` | 在家人端「绑定码 / 邀请」生成 6 位码 |

## 3. 8 分钟路径

### 0:00–0:40 角色与定位

- 打开 `/`：一句话说明「给江苏长辈的 AI 陪伴与守护，家人也能协同」。
- 指出三个角色：长辈、家人、机构（即将开放）。
- 点「长辈演示」进入陪伴屏。

### 0:40–1:40 长辈陪伴屏（`/elder`）

- 大字号、四个大按钮：吃药、防骗、吃饭、找不到家。
- 点「念给我听」让 AI 今日简报朗读出来。
- 如果刚重置过数据，简报下方会出现一条未读家人留言「妈，今天降温…」：
  - 点「念给我听」让系统读出来；
  - 点「知道了」标记已读并收起。
- 说明：简报综合了用药、天气、位置与记忆，不是固定文案。

### 1:40–3:20 语音 + 工具调用 + 可解释轨迹（`/elder/chat`）

1. 先展示小助手首页：三张卡分别是用药、位置安全、最近回忆，下面是未读家人留言和 AI 今日简报。
2. 点麦克风，说：**「我头有点晕，今天饮食该注意什么？」**
3. 识别结果先回填输入框，点确认后发送（避免误识别直接发出去）。
4. 回答会调用 `get_diet_plan`，结合高血压/糖尿病与用药忌口。
5. 点「查看 AI 决策轨迹」：
   - 看到真实模型、耗时（约 3–4 秒）
   - 工具名、工具结果、决策与置信度
   - 明确「这是结构化依据，不是模型思维原文」

> 讲解点：普通聊天机器人只会生成文字；这里会**选工具、取真实数据、留痕**，首页也会先给出今天的上下文。

### 3:20–4:40 反诈（`/elder/safety/scam`）

1. 点示例「冒充公检法」，输入框自动填入：**「我是警察，你涉嫌洗钱，请把钱转到安全账户，不要告诉家里人。」**
2. 点「开始鉴定」：结果高风险 / 冒充公检法 / 置信度约 98%，逐条列出「安全账户」「不要告诉家里人」等可疑点。
3. 指出底部依据来源与「不构成权威结论」的免责声明。
4. 可选：点「启动转账冷静期」，家人端会收到确认请求。
5. 结尾指一下「先记住这三句话」：公检法不会让您转账、不点陌生链接、拿不准先停一停。

### 4:40–5:40 守护闭环（`/elder/safety`）

1. 点「模拟走出围栏」（演示用）。
2. 守护 Agent 给出风险研判与建议。
3. 切到家人端 `/family`：实时看到告警、研判、待确认；可切换长辈。
4. 说明：真实设备接入时，位置来自手机/手表适配层，当前演示用模拟位置。

### 5:40–6:40 记忆与故事（`/elder/story`）

- 打开「一家人的年夜饭」：故事由访谈生成，带口述依据。
- 说明：AI 不编造，故事引语会校验；可朗读、导出。

### 6:40–7:30 家人协同与健康档案

- `/family`：页面顶部先显示「有 N 项需要关注」，待确认事项排在消息前面。
- 周报区有本周用药依从率进度条（演示种子约 86%）和四段建议。
- 在「与长辈的消息」里点一条快捷回复（如「记得按时吃药」），再点发送；切回长辈端陪伴屏，留言条会出现。
- `/family/profile`：修改慢病/过敏/家庭住址，长辈端饮食建议随之更新。
- 强调：一个家人账号可绑定多位长辈，顶栏切换，数据按长辈隔离。

### 7:30–8:00 收尾

- 技术：React + Fastify + MySQL、systemd 部署、SSE/WS、真实 Qwen 模型。
- 评测：反诈/故事/Agent 15 题自动评测，指标见 `docs/评测报告.md`。
- 边界：不替代医生诊断与警方判断；演示数据为虚构；语音识别依赖浏览器云服务。

## 4. 可能被问到的问题

| 问题 | 回答要点 |
| --- | --- |
| 和普通聊天机器人有什么区别？ | 工具体系（位置/用药/天气/反诈知识库）、风险分级与确认门、主动简报、决策轨迹可解释。 |
| AI 用的什么模型？ | Qwen（OpenAI 兼容网关），统一走 ModelRouter；失败自动回落本地兜底。 |
| 数据是真的吗？ | 演示数据为虚构种子；真实接入时来自健康档案、用药记录、位置适配层与家庭留言。 |
| 老人不会用怎么办？ | 陪伴屏四个大按钮、语音优先、识别后确认再发送、家人可代设健康档案与绑定。 |
| 隐私怎么保证？ | 敏感字段加密、HttpOnly Cookie、RBAC 与长辈归属校验、日志脱敏、数据保留期清理。 |
| 能上线吗？ | 已在阿里云 systemd + MySQL 8 运行；正式 HTTPS 需域名与备案，语音演示用 localhost/HTTPS。 |
| 评测怎么证明有效？ | `npm run eval` 可复现，15 题覆盖风险等级、类型、引文忠实度与结构化输出。 |

## 5. 故障预案

| 情况 | 处理 |
| --- | --- |
| 语音识别报 `network` | 换 Edge；仍失败就打字，不影响 AI 演示。 |
| 麦克风无权限 | 地址栏允许麦克风；确认是 localhost/HTTPS。 |
| 模型超时/欠费 | 后端会自动回落本地兜底，轨迹里会标注「本地兜底」；继续演示。 |
| 页面数据被改乱 | `npm run reset:demo -- --yes`，刷新页面。 |
| 家人端没收到实时告警 | 刷新 `/family`；检查顶部「实时连接」状态。 |

## 6. 演示后

```bash
npm run reset:demo -- --yes
```

重置会保留知识库与评测记录，登录状态不变。
