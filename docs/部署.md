# 部署与在线演示

生产模式由一个 Fastify 进程同时提供 API、上传文件与前端静态页面，前端路由由服务端回退到 `index.html`。

## 方式一：本地生产预演

```bash
npm ci
npm run build

# 在 apps/api 工作目录下启动（npm workspace 会自动切换）
NODE_ENV=production \
SESSION_SECRET=replace-with-a-long-random-string \
DEMO_MODE=1 \
npm run start -w apps/api
```

打开 <http://127.0.0.1:3100>。若没有配置任何模型 Key，后端会自动使用 Mock 模型，页面仍可完整体验。

前端构建目录默认是 `frontend/dist`（相对仓库根目录），可通过 `WEB_DIST_DIR` 覆盖；上传文件默认写入 `apps/api/public/uploads`，可通过 `PUBLIC_DIR` 覆盖。

## 方式二：Docker Compose

```bash
# 建议先在 .env 中设置 SESSION_SECRET
docker compose up -d --build
docker compose logs -f app
```

- 访问地址：<http://服务器IP:3100>
- 数据卷：`app-data`（SQLite 与主密钥）、`app-public`（上传图片）
- 健康检查：`GET /health`；就绪检查：`GET /ready`

> 演示环境默认 `DEMO_MODE=1`。正式环境请删除该变量，并接入真实登录。

## 数据库初始化

本项目使用 **SQLite 单文件数据库**，不需要在服务器上安装 MySQL/PostgreSQL，也不需要先建库。

- 数据库文件：`$DATA_DIR/app.db`，默认 `apps/api/data/app.db`；主密钥在同目录的 `master.key`。
- 后端启动时自动执行 `apps/api/src/store/migrations.ts` 建表，语句幂等；`DEMO_MODE=1` 时还会写入李奶奶等演示数据。
- Docker 部署时，`app-data` 卷挂载到 `/app/data`，`docker compose up -d` 即自动完成建库。
- 健康检查：`GET /health`；就绪检查：`GET /ready`（会检查数据库连接）。

如需手动初始化或给 DBA 审计，可使用仓库中的 [schema.sql](schema.sql)（由迁移代码生成，29 张表 + 12 个索引）：

```bash
# 服务器需要安装 sqlite3 CLI；也可以在本地执行后上传 app.db
sqlite3 /path/to/app.db < docs/schema.sql
```

- 脚本只建表，不写演示数据，可重复执行。
- 修改表结构时，先改 `migrations.ts`，再运行 `npm run db:schema` 重新生成，不要手改 `schema.sql`。
- **如果要用 MySQL/PostgreSQL**：当前仓储层基于 `node:sqlite`，需要单独适配数据访问层，不能只执行一份 DDL。

### 备份

同时备份 `app.db` 与 `master.key`，否则加密字段（记忆、位置、联系方式等）无法解密。SQLite 开启 WAL，备份前建议先停止服务或执行 `sqlite3 app.db ".backup backup.db"`。

## 环境变量

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `NODE_ENV` | `development` | 设为 `production` 后启用前端静态托管与 SPA 回退 |
| `PORT` / `HOST` | `3100` / `127.0.0.1` | 容器内请设为 `0.0.0.0` |
| `SESSION_SECRET` | 开发默认值 | **生产必填**，用于 HMAC 会话签名 |
| `DEMO_MODE` | 关闭 | `1` 时开放演示账号与种子数据 |
| `DATA_DIR` | `./data` | SQLite 数据库与 `master.key` |
| `PUBLIC_DIR` | `./public` | 上传文件根目录 |
| `WEB_DIST_DIR` | `../../frontend/dist` | 前端构建产物目录（相对 `apps/api`） |
| `APP_BASE_URL` | `http://localhost:5173` | 对外访问地址，用于海报等链接 |
| `LLM_MOCK` | 自动 | `1` 强制 Mock；无任何模型 Key 时也会自动 Mock |
| `DEEPSEEK_API_KEY` / `QWEN_API_KEY` / `ARK_API_KEY` | 空 | 任选其一即可启用真实模型 |
| `AMAP_WEB_KEY` | 空 | 高德 Web 服务 Key；留空时天气返回演示数据 |
| `LLM_TIMEOUT_MS` | `20000` | 单次模型调用超时 |

完整变量见 [apps/api/.env.example](../apps/api/.env.example)。

## 反向代理（可选）

生产环境建议在 Nginx / Caddy 后启用 HTTPS。SSE 与 WebSocket 需要关闭缓冲并支持升级。

```nginx
server {
  listen 443 ssl http2;
  server_name example.com;

  location / {
    proxy_pass http://127.0.0.1:3100;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
  }

  location /api/agent/chat {
    proxy_pass http://127.0.0.1:3100;
    proxy_http_version 1.1;
    proxy_buffering off;
    proxy_cache off;
    proxy_read_timeout 300s;
    add_header X-Accel-Buffering no;
  }

  location /ws {
    proxy_pass http://127.0.0.1:3100;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 300s;
  }
}
```

设置 `APP_BASE_URL=https://example.com`，并确保 `SESSION_SECRET` 足够长且只保存在服务器环境变量中。

## 数据卷与上传文件

- 上传文件：`$PUBLIC_DIR/uploads/`。
- 升级镜像前先备份 `app-data` 数据卷；`docker compose down` 不会删除具名卷。

## 数字人（可选）

DH_live 数字人服务是独立的 Python 进程，不包含在本镜像内。未启动时，前端会使用浏览器语音与静态头像，不影响其他功能。需要展示数字人时：

1. 按 DH_live 文档启动其 Web 服务；
2. 通过 Nginx 将 `/dh-live-api/` 与 `/dh-live-static/` 转发到该服务；
3. 或仅在演示机本地运行 DH_live，生产环境使用默认降级方案。
